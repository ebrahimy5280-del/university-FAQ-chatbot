# 🎓 چت‌بات هوشمند FAQ دانشگاه مبتنی بر RAG

این پروژه یک چت‌بات هوشمند برای پاسخ‌گویی به سوالات متداول دانشگاهی است که با بهره‌گیری از معماری **RAG (Retrieval-Augmented Generation)** طراحی و پیاده‌سازی شده است.

---

## 📌 مشخصات پروژه

* **نگارش و پیاده‌سازی:** ابراهیم یدالهی
* **استاد راهنما:** سرکار خانم جوکار
* **دانشگاه:** دانشکده فنی و حرفه‌ای پسران شماره یک شیراز (شهید باهنر)
* **مقطع و رشته:** کارشناسی مهندسی حرفه‌ای کامپیوتر

---

## ✨ امکانات پروژه

* پاسخ‌گویی هوشمند به سوالات متداول دانشگاه
* استفاده از تکنیک RAG برای بازیابی اطلاعات مرتبط
* استفاده از پایگاه داده برداری **ChromaDB** برای جستجوی معنایی
* رابط کاربری تعاملی تحت وب با **Streamlit**
* ارائه وب‌سرویس با **FastAPI**
* امکان استفاده از چت‌بات از طریق **Telegram**
* ذخیره‌سازی محلی تاریخچه گفتگوها

## 🛠 فناوری‌های استفاده شده

* **زبان برنامه‌نویسی:** Python 3.10+
* **فریم‌ورک ارکستراسیون:** LangChain
* **پایگاه داده برداری:** ChromaDB
* **مدل زبانی:** gpt-4o-mini
* **مدل Embedding:** text-embedding-3-small
* **ارائه مدل‌های هوش مصنوعی:** AvalAI
* **رابط کاربری وب:** Streamlit
* **وب‌سرویس:** FastAPI
* **ارتباط با Telegram:** Requests و Telegram Bot API

## 🚀 نصب و راه‌اندازی

### ۱. نصب وابستگی‌ها

ابتدا Python را نصب کرده و سپس وابستگی‌های پروژه را با دستور زیر نصب کنید:

```bash
pip install -r requirements.txt
```

### ۲. تنظیم متغیرهای محیطی

فایل `.env.example` را به `.env` تبدیل کرده و مقادیر مورد نیاز را در آن قرار دهید:

```text
AVALAI_API_KEY=YOUR_AVALAI_API_KEY_HERE
TELEGRAM_TOKEN=YOUR_TELEGRAM_BOT_TOKEN_HERE
```

> ⚠️ **نکته امنیتی:** فایل `.env` حاوی کلیدهای محرمانه است و نباید در GitHub آپلود شود.

## 💻 دستورات اجرا

### اجرای رابط کاربری وب (Streamlit)

برای اجرای رابط کاربری پروژه:

```bash
streamlit run app.py
```

---

### اجرای وب‌سرویس (FastAPI)

برای اجرای API:

```bash
uvicorn api:app --reload
```

پس از اجرای سرویس، مستندات تعاملی Swagger از مسیر زیر در دسترس خواهد بود:

```text
http://127.0.0.1:8000/docs
```

---

### اجرای ربات تلگرام

برای اجرای ربات تلگرام:

```bash
python bot_telegram.py
```
