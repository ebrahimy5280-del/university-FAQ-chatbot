# 🎓 چت‌بات هوشمند FAQ دانشگاه مبتنی بر RAG

این پروژه یک **چت‌بات هوشمند برای پاسخ‌گویی به سوالات متداول دانشگاهی (FAQ)** است که با استفاده از معماری **RAG (Retrieval-Augmented Generation)** طراحی و پیاده‌سازی شده است.

هدف اصلی پروژه، ایجاد یک سامانه هوشمند است که بتواند سوالات کاربران را دریافت کرده، اطلاعات مرتبط را از پایگاه دانش دانشگاه بازیابی کرده و با استفاده از یک مدل زبانی، پاسخ مناسب و قابل فهم تولید کند.

در این پروژه از پایگاه داده برداری **ChromaDB** برای جستجوی معنایی، از مدل‌های Embedding برای تبدیل متن به بردار و از مدل زبانی برای تولید پاسخ نهایی استفاده شده است.

---

## 📌 معرفی پروژه

در بسیاری از محیط‌های دانشگاهی، دانشجویان سوالات متداولی درباره موضوعاتی مانند قوانین آموزشی، ثبت‌نام، انتخاب واحد، امور دانشجویی و سایر خدمات دانشگاه دارند.

هدف این پروژه، پیاده‌سازی یک دستیار هوشمند است که بتواند به این سوالات به صورت سریع و خودکار پاسخ دهد.

معماری پروژه بر اساس روش **RAG** طراحی شده است. در این روش، ابتدا سوال کاربر به صورت معنایی بررسی و اطلاعات مرتبط از پایگاه دانش بازیابی می‌شود. سپس اطلاعات بازیابی‌شده در اختیار مدل زبانی قرار می‌گیرد تا پاسخ نهایی تولید شود.

استفاده از RAG باعث می‌شود پاسخ‌های چت‌بات تا حد امکان بر اساس اطلاعات موجود در پایگاه دانش پروژه تولید شوند.

### توضیح فایل‌های اصلی

* `app.py`
  رابط کاربری تحت وب پروژه با استفاده از Streamlit.

* `api.py`
  پیاده‌سازی وب‌سرویس پروژه با استفاده از FastAPI.

* `bot_telegram.py`
  بخش مربوط به ارتباط چت‌بات با Telegram.

* `rag_engine.py`
  هسته اصلی منطق RAG، شامل بازیابی اطلاعات و تولید پاسخ.

* `data/faq.json`
  پایگاه دانش شامل سوالات و اطلاعات متداول دانشگاه.

* `requirements.txt`
  فهرست کتابخانه‌ها و وابستگی‌های مورد نیاز پروژه.

* `.env.example`
  نمونه فایل متغیرهای محیطی مورد نیاز.

* `.gitignore`
  مشخص می‌کند چه فایل‌هایی نباید در Git ذخیره یا در GitHub آپلود شوند.

* `chat_logs/`
  محل ذخیره تاریخچه گفتگوهای انجام‌شده.

این فرآیند باعث می‌شود مدل زبانی هنگام تولید پاسخ، از اطلاعات موجود در پایگاه دانش پروژه استفاده کند.

# 🔍 تحلیل نتایج

پس از پیاده‌سازی و اجرای پروژه، چت‌بات توانست برای سوالات موجود در حوزه FAQ دانشگاه، پاسخ‌هایی بر اساس اطلاعات موجود در پایگاه دانش تولید کند.

استفاده از معماری RAG باعث شد سیستم بتواند قبل از تولید پاسخ، اطلاعات مرتبط با سوال کاربر را بازیابی کند. این موضوع باعث می‌شود پاسخ‌ها نسبت به حالتی که مدل زبانی بدون دسترسی به پایگاه دانش مورد استفاده قرار گیرد، بیشتر به اطلاعات اختصاصی پروژه وابسته باشند.

همچنین استفاده از **ChromaDB** امکان جستجوی معنایی را فراهم کرده است؛ بنابراین سیستم می‌تواند سوال کاربر را از نظر مفهومی با اطلاعات موجود در پایگاه دانش مقایسه کند.

### نتایج کلی پروژه

* امکان پاسخ‌گویی خودکار به سوالات متداول
* کاهش نیاز به جستجوی دستی در اطلاعات دانشگاه
* امکان استفاده از جستجوی معنایی
* استفاده از اطلاعات اختصاصی موجود در پایگاه دانش
* امکان دسترسی از طریق رابط وب
* امکان دسترسی از طریق API
* امکان استفاده از ربات Telegram

### محدودیت‌های پروژه

عملکرد چت‌بات به کیفیت و کامل بودن پایگاه دانش `faq.json` وابسته است. در صورتی که پاسخ سوالی در پایگاه دانش وجود نداشته باشد یا اطلاعات کافی برای آن موجود نباشد، کیفیت پاسخ ممکن است کاهش پیدا کند.

همچنین کیفیت پاسخ نهایی به عملکرد مدل زبانی و کیفیت اطلاعات بازیابی‌شده وابسته است.
