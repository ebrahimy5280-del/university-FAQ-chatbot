## 📌 معرفی پروژه

این پروژه یک **چت‌بات هوشمند برای پاسخ‌گویی به سؤالات متداول دانشگاهی (FAQ)** است که با استفاده از معماری **RAG (Retrieval-Augmented Generation)** طراحی و پیاده‌سازی شده است.

هدف اصلی پروژه، ایجاد یک سامانه هوشمند است که بتواند سؤال کاربر را دریافت کرده، اطلاعات مرتبط را از پایگاه دانش دانشگاه بازیابی کند و سپس با استفاده از یک مدل زبانی، پاسخ مناسب و قابل فهم تولید نماید.

در این پروژه از **ChromaDB** به عنوان پایگاه داده برداری برای جستجوی معنایی، از مدل‌های **Embedding** برای تبدیل متن به بردار و از یک **مدل زبانی** برای تولید پاسخ نهایی استفاده شده است.
