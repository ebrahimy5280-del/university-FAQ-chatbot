# 🎓 چت‌بات هوشمند FAQ دانشگاه مبتنی بر RAG

این پروژه یک **چت‌بات هوشمند برای پاسخ‌گویی به سؤالات متداول دانشگاهی (FAQ)** است که با استفاده از معماری **RAG (Retrieval-Augmented Generation)** طراحی و پیاده‌سازی شده است.

هدف اصلی پروژه، ایجاد یک سامانه هوشمند است که بتواند سؤالات کاربران را دریافت کرده، اطلاعات مرتبط را از پایگاه دانش دانشگاه بازیابی کرده و با استفاده از یک مدل زبانی، پاسخ مناسب و قابل فهم تولید کند.

در این پروژه از **ChromaDB** به عنوان پایگاه داده برداری برای جستجوی معنایی، از مدل‌های **Embedding** برای تبدیل متن به بردار و از مدل زبانی برای تولید پاسخ نهایی استفاده شده است.

---

## 📌 معرفی پروژه

در بسیاری از محیط‌های دانشگاهی، دانشجویان سؤالات متداولی درباره موضوعاتی مانند قوانین آموزشی، ثبت‌نام، انتخاب واحد، امور دانشجویی و سایر خدمات دانشگاه دارند.

هدف این پروژه، پیاده‌سازی یک دستیار هوشمند است که بتواند به این سؤالات به صورت سریع و خودکار پاسخ دهد.

معماری پروژه بر اساس روش **RAG** طراحی شده است. در این روش، ابتدا سؤال کاربر به صورت معنایی بررسی شده و اطلاعات مرتبط از پایگاه دانش بازیابی می‌شود. سپس اطلاعات بازیابی‌شده در اختیار مدل زبانی قرار می‌گیرد تا پاسخ نهایی تولید شود.

استفاده از RAG باعث می‌شود پاسخ‌گویی سیستم تا حد امکان بر اساس اطلاعات موجود در پایگاه دانش پروژه انجام شود.

## 📄 توضیح فایل‌های اصلی

### `app.py`

رابط کاربری تحت وب پروژه با استفاده از Streamlit است.

این فایل محیط چت، نمایش پیام‌های کاربر و پاسخ چت‌بات، مدیریت جلسه گفتگو و ذخیره محلی تاریخچه گفتگوها را فراهم می‌کند.

### `api.py`

وب‌سرویس پروژه با استفاده از FastAPI در این فایل پیاده‌سازی شده است.

Endpoint اصلی برای ارسال سؤال:

```text
POST /ask
```

همچنین endpoint زیر برای بررسی وضعیت سرویس استفاده می‌شود:

```text
GET /
```

مستندات تعاملی API نیز از مسیر زیر قابل دسترسی است:

```text
/docs
```

### `bot_telegram.py`

این فایل مسئول ارتباط چت‌بات با Telegram Bot API است و امکان دریافت پیام و ارسال پاسخ از طریق Telegram را فراهم می‌کند.

### `rag_engine.py`

هسته اصلی منطق چت‌بات در این فایل قرار دارد.

وظایف اصلی این فایل شامل:

- بارگذاری متغیرهای محیطی
- اتصال به سرویس AvalAI
- بارگذاری پایگاه دانش
- ایجاد Embedding
- ایجاد Vector Store با ChromaDB
- بازیابی اسناد مرتبط
- ساخت Prompt
- ارسال Context و سؤال به مدل زبانی
- تولید پاسخ نهایی

### `data/faq.json`

پایگاه دانش پروژه است و شامل سؤالات و پاسخ‌های متداول مورد استفاده سامانه می‌باشد.

### `requirements.txt`

فهرست کتابخانه‌ها و وابستگی‌های موردنیاز پروژه را مشخص می‌کند.

### `.env.example`

نمونه‌ای از متغیرهای محیطی موردنیاز پروژه است و شامل مقادیر واقعی یا محرمانه نیست.

### `.gitignore`

فایل‌ها و اطلاعاتی را که نباید در GitHub منتشر شوند مشخص می‌کند؛ از جمله `.env`، فایل‌های Cache، تاریخچه گفتگوها و فایل‌های موقت.

### `assets/`

این پوشه شامل تصاویر و نمودارهای مرتبط با پروژه است.

این پروژه یک نمونه دانشگاهی و کاربردی است و برای استفاده در محیط عملیاتی بزرگ، نیازمند توسعه بیشتر در حوزه‌هایی مانند مدیریت کاربران، احراز هویت، مقیاس‌پذیری، مانیتورینگ و مدیریت پیشرفته پایگاه دانش خواهد بود.

- افزودن سیستم احراز هویت کاربران

## 📌 جمع‌بندی

این پروژه یک نمونه کاربردی از استفاده از هوش مصنوعی و معماری **Retrieval-Augmented Generation (RAG)** در حوزه خدمات دانشگاهی است.

سیستم با ترکیب پایگاه دانش، جستجوی معنایی، پایگاه داده برداری و مدل زبانی، امکان پاسخ‌گویی هوشمند به سؤالات متداول را فراهم می‌کند.

همچنین با ارائه رابط کاربری وب، API و ربات Telegram، امکان استفاده از سیستم از طریق روش‌های مختلف فراهم شده است.

ساختار پروژه، وابستگی‌ها، روش نصب، نحوه اجرا، پایگاه دانش، تصاویر، نمودارها و ملاحظات امنیتی در این README مستند شده‌اند تا استفاده و بازتولید پروژه برای سایر کاربران امکان‌پذیر باشد.
